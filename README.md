# salman. — UX/UI design portfolio

Portfolio of **Salman Bhatti**, UX/UI designer based in Germany.

**Live site:** https://salmanportfolio-inky.vercel.app

## What's inside

- **Hero:** an interactive 3D avatar (three.js). Scrolling moves the camera through my education and experience.
- **Projects:** case studies for Sumato ERP, ARound the Market (AR for Christmas markets), muq. smart coffee app, All In One Electric, EDEN smart terrarium and Naija Living.
- **Testimonials, tools & methods, travel log** and a separate links page.
- Dark and light themes, responsive from phones to wide screens.

## Built with

Plain HTML, CSS and JavaScript, with [three.js](https://threejs.org) for the 3D avatar. No build step. Hosted on Vercel.

## Run locally

Open the folder in VS Code and start **Live Server** on `index.html`, or run any static server:

```
npx serve .
```
